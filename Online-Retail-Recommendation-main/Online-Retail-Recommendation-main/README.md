## Project Overview

The Online Retail Recommendation System is a Python-based
application that analyses customer purchasing behaviour
and recommends relevant products.

## Objectives

- Analyse retail transaction data.
- Identify popular products.
- Generate personalized product recommendations.
- Explore product categories and sales.
- Visualize retail business performance.

## Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Matplotlib
- Pytest

## Recommendation Techniques

1. Popularity-Based Recommendation:
   Products are ranked using total units purchased.

2. Item Co-occurrence Recommendation:
   Products are suggested based on products purchased
   by customers with similar purchase histories.

## Dataset

The project uses 1,800 synthetically generated retail
transactions.
